# 优惠券独立管理页升级

现有数据库已经执行过 `coupon-management.sql` 时，只执行 `coupon-menu-upgrade.sql`，不要再次运行建表脚本。

1. 在当前业务数据库执行 `coupon-menu-upgrade.sql`。脚本可重复执行，将“优惠券管理”移动至“商品管理”同级，并补齐与商品管理一致的角色菜单授权。
2. 构建、发布本次后端和管理端前端代码。新页面路由仍为 `/#/manage/coupon`，组件为 `manage/coupon/Coupon`。
3. 重新登录或刷新后台，重新获取菜单。

全新环境按原部署流程执行 `coupon-management.sql` 即可，菜单层级已修正。

优惠券支持按名称、适用类型、启用状态查询，以及新增、详情、编辑、删除。创建或编辑时选择全场通用券，或选择多个商品的商品专用券；可设置金额/折扣、使用门槛、有效期、活动时间、领取总量与启用状态。

删除采用逻辑删除（`coupon_template.status = -1`），从管理列表和小程序可领取列表移除，保留优惠券模板、关联商品及用户领取记录。停用（`status = 0`）可通过编辑重新启用，删除后不可恢复。编辑不会重置已领取数量，清空总量或活动时间可恢复不限量/不限时间。
